# セキュリティポリシー / Security policy

脆弱性の報告は [GitHub の非公開報告フォーム](https://github.com/tin-machine/cli-tool-docker/security/advisories/new) からお願いします。
影響を受けるバージョンまたはコミット、利用環境、確認した影響を記載してください。
一般的な不具合や要望は [Issues](https://github.com/tin-machine/cli-tool-docker/issues) で受け付けます。

Report security vulnerabilities using [GitHub's private reporting form](https://github.com/tin-machine/cli-tool-docker/security/advisories/new).
Include the affected version or commit, the environment, and the observed impact.
Use [Issues](https://github.com/tin-machine/cli-tool-docker/issues) for general bugs and feature requests.
